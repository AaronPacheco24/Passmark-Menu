"# Passmark-Menu

Passmark-Menu is a Python-based utility for managing workflow tools, hardware checks, and product information in a single installer-style package.

## Overview

This project provides a menu-driven interface for launching hardware validation scripts, reviewing product metadata, and coordinating related setup actions. It is designed to be flexible, easy to use, and adaptable to several deployment environments.

## Key features

- Menu interface for selecting and running available tools
- Hardware check integration for system validation
- Product metadata storage and lookup via JSON
- Modular design for adding new utilities and scripts

## Getting started

1. Install Python 3.8+.
2. Run the main application from `src/main.py`.
3. Use the available menu options to launch checks or review product details.

## Project structure

- `src/main.py` - main application entry point
- `src/customer_kickoff.py` - kickoff workflow support
- `src/product_info.json` - product metadata and configuration
- `src/HardwareCheck/` - hardware check scripts and related assets

## Notes

This repository is intended as a general-purpose menu utility and can be customized for different operational workflows.
